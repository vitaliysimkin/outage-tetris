# outage-tetris

Графік відключень електроенергії у стилі Тетріса. Статична сторінка (HTML/CSS/JS), без бекенду — підходить для GitHub Pages.

Дані графіка редагуються у [data.js](data.js): масив груп, годин та матриця `0`/`1` (нема світла / є світло).

## Локальний перегляд

```
python3 -m http.server 8080
```

і відкрити http://localhost:8080
