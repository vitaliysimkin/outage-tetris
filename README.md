# outage-tetris

Повноцінний Тетріс у стилі графіка відключень електроенергії. Статична сторінка (HTML/CSS/JS, canvas), без бекенду — підходить для GitHub Pages. Працює на мобільних: кнопки керування + свайпи по полю.

Керування: стрілки / swipe вліво-вправо-вниз, тап (або ↑/X) — обертання, пробіл (або кнопка ⤓) — миттєве падіння, P — пауза.

## Локальний перегляд

```
python3 -m http.server 8080
```

і відкрити http://localhost:8080
