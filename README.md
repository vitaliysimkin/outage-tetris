# outage-tetris

Тетріс, де ігрове поле — графік відключень: 10 колонок-груп (1.1–5.2) × 24 години. Фігура, що падає, — «світло є», складені блоки — «світла немає».

Гра: https://vitaliysimkin.github.io/outage-tetris/

Тільки фронт (HTML/CSS/JS), без збірки — працює на GitHub Pages.

## Керування

- Кнопки: ◀ ▶ рух, ↻ обертання, ▼ вниз (утримання — повтор), ⤓ скинути, ❚❚ пауза, ↺ нова гра
- Поле: тап — обертання, свайп вліво/вправо/вниз — рух, швидкий свайп вниз — скинути
- Клавіатура: стрілки, ↑/X — обертання, Z — обертання назад, пробіл — скинути, P/Esc — пауза
